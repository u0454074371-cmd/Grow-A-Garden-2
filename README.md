# Grow Garden 2 — FINAL PLAYABLE

Deze build heeft GEEN loading screen en wacht NIET op Firebase.

Bestanden:
- index.html
- style.css
- scripts/main.js

Upload deze bestanden naar de root van GitHub Pages en verwijder de oude bestanden eerst.

Gameplay:
- WASD lopen
- muis rondkijken
- Shift sprint
- Space springen
- E planten/oogsten
- Shop
- Pets
- lokale save

Firebase wordt in deze build bewust niet gebruikt voor de start van de game. Daardoor kan Firebase de game niet blokkeren.

Hard refresh na uploaden:
Ctrl+F5 (Windows) / Cmd+Shift+R (Mac).
